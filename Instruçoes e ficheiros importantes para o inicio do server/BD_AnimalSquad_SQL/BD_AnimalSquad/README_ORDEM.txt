Animal Squad - Entrega de Bases de Dados

Ordem aconselhada para correr no MySQL Workbench:

1. create.sql
   - Cria a base de dados animal_squad e todas as tabelas.
   - ATENCAO: apaga a base de dados antiga, se ela existir.

2. logic.sql
   - Cria views, functions, procedures e triggers.

3. populate.sql
   - Insere dados iniciais: users, animals, maps, missions, progressos e uma partida de exemplo.

4. queries.sql
   - Consultas para demonstrar a base de dados.

5. test_triggers.sql
   - Testes especificos dos triggers.

6. test.sql
   - Teste global: compra animal, completa missao, cria partida e mostra estatisticas.

Ficheiros pedidos:
- create.sql
- logic.sql
- populate.sql
- queries.sql
- test_triggers.sql
- test.sql
